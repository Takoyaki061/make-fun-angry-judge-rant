A short, funny rant about an everyday annoyance — a self-checkout machine that detains a shopper over a bag of rice — written for make.fun's "Angry Judge: The Short Rant Contest". The program writes the rant to `/output/entry.txt`, where a furious judge reads it two at a time against the other entries and picks the one that lands hardest.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
